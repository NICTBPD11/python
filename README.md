📖 About

NICT Python Academy is a modern, interactive learning platform created specifically for students of the NICT Python course. This web application transforms traditional Python lecture notes into an engaging, self-paced learning experience with beautiful UI/UX design inspired by contemporary educational platforms.

Built with ❤️ for beginners who want to master Python programming in a fun, visual, and interactive way.

✨ Features

🎯 Core Learning Features
12 Comprehensive Topics — From Python basics to Data Visualization
Interactive Quizzes — Multiple practice questions per topic with instant feedback
Detailed Explanations — Every quiz includes explanations to reinforce learning
Code Examples — Real Python code snippets with expected outputs
Syntax Highlighting — Beautiful Python code highlighting for better readability
Key Points — Important concepts summarized in easy-to-digest cards

🎨 UI/UX Features
Modern Design — Clean, contemporary interface inspired by gokiwi.in
Progress Tracking — Visual progress bar showing course completion
Local Storage — Your progress is saved automatically in the browser
Bookmark System — Save important topics for quick access
Responsive Layout — Works seamlessly on desktop, tablet, and mobile
Copy Code Button — One-click code copying for easy practice
Dark Code Editor — Professional-looking code blocks with output display

🧭 Navigation
Sidebar Navigation — Quick access to all 12 topics
Topic Progress Indicators — Visual cues for visited and completed topics
Previous/Next Navigation — Sequential learning flow
Quiz Navigation Dots — Jump between multiple quiz questions

📚 Curriculum

The course covers the following 12 comprehensive topics:

| # | Topic | Description |
|---|-------|-------------|
| 1 | 🚀 Introduction to Python | History, features, installation, and first program |
| 2 | 📦 Python Basics | Identifiers, keywords, variables, operators, data types |
| 3 | 🔄 Control Flow | If-else, loops, break, continue, range() |
| 4 | 📝 Strings | String creation, methods, slicing, formatting |
| 5 | 📋 Lists | List operations, methods, stacks & queues |
| 6 | 📖 Dictionaries | Key-value pairs, methods, iteration |
| 7 | ⚡ Functions | Defining functions, arguments, recursion, scope |
| 8 | 🛡️ Exception Handling | Try-except-else-finally, common exceptions |
| 9 | 📁 File Handling | Reading, writing, file modes, paths |
| 10 | 🏗️ Object-Oriented Programming | Classes, objects, inheritance, encapsulation |
| 11 | 🖥️ GUI with Tkinter | Building desktop applications with widgets |
| 12 | 🗄️ SQLite Database | Database operations with SQL |
| 13 | 📊 Data Visualization | Charts and graphs with Matplotlib |

🚀 Getting Started

Prerequisites
A modern web browser (Chrome, Firefox, Edge, Safari)
No server required! Runs entirely in the browser

Installation

Clone or Download the repository:
   bash
   git clone https://github.com/yourusername/nict-python-academy.git
   
Open the file in your browser:
   - Double-click index.html, OR
   - Use a live server (VS Code Live Server, Python http.server, etc.)

Start Learning! 🎉

Using Python http.serverbash
Navigate to project folder
cd nict-python-academy

Start local server
python -m http.server 8000

Open in browser
http://localhost:8000
